# AI Research Assistant 🤖

## 📌 Overview

The **AI Research Assistant** is a Python-based AI application designed to help users perform research-related tasks efficiently. It uses a Large Language Model (LLM) and AI tools to answer questions, retrieve relevant information, and assist with research activities.

The project demonstrates the practical implementation of AI agents, tool integration, and automated task handling using modern AI engineering technologies.

## ✨ Features

- **AI-Powered Responses:** Generates answers to user questions using an LLM.
- **Tool Integration:** Allows the agent to use available tools to perform specific tasks.
- **Research Assistance:** Helps users explore topics and work with research information.
- **Modular Architecture:** Separates agent logic, tools, and application entry points into different Python files.
- **Environment Configuration:** Uses environment variables to manage API credentials.
- **Extensible Design:** Can be extended with additional tools, document retrieval, and other AI capabilities.

## 🛠️ Technologies Used

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/AI-Research-Assistant.git
cd AI-Research-Assistant
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it on Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables

Create a `.env` file in the project root and add the API key required by your application.

For example, if the project uses Groq:

```env
GROQ_API_KEY=your_api_key_here
```

**Security note:** Never upload your actual `.env` file or API keys to GitHub.

### 5. Run the Application

```bash
python main.py
```
